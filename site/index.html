NW3D-01

Stolní robot, který očima ukazuje průběh tisku na tiskárně Bambu Lab, hodiny, počasí a kurzy. Tady do něj nahraješ firmware – bez instalace programů. A desk robot whose eyes show your Bambu Lab print progress, a clock, weather and tickers. Install its firmware right here – no software to install.

Co potřebuješWhat you need

  • desku Waveshare ESP32-S3-DualEye-LCD-1.28 (dva kulaté displeje),
  • a Waveshare ESP32-S3-DualEye-LCD-1.28 board (two round displays),
  • datový kabel USB-C (některé kabely jen nabíjejí),
  • a USB-C data cable (some cables only charge),
  • počítač s prohlížečem Chrome nebo Edge (případně Android s Chrome). iPhone a Safari to neumí.
  • a computer with Chrome or Edge (or Android with Chrome). iPhone and Safari are not supported.

PostupSteps

  1. Připoj desku kabelem k počítači.
  2. Klikni na Nainstalovat firmware a vyber port desky (obvykle USB JTAG/serial debug unit).
  3. Potvrď instalaci. Při první instalaci nech zaškrtnuté smazání zařízení. Nahrávání trvá asi minutu.
  4. Po nahrání zadej Wi-Fi a heslo (jen síť 2,4 GHz). Robot se připojí a ukáže odkaz.
  5. Otevři http://nw3d-robot.local a projdi průvodce: jazyk, přihlášení k Bambu účtu, výběr tiskárny a město pro počasí.
  1. Connect the board to your computer.
  2. Click Install firmware and pick the board's port (usually USB JTAG/serial debug unit).
  3. Confirm. On the first install keep "erase device" checked. Flashing takes about a minute.
  4. Then enter your Wi-Fi and password (2.4 GHz only). The robot connects and shows a link.
  5. Open http://nw3d-robot.local and follow the wizard: language, Bambu account sign-in, printer and your city for the weather.

Bez počítače: po nahrání se robot, který nezná Wi-Fi, ozve vlastní sítí NW3D-xxxx. Připoj se k ní telefonem a otevře se nastavení. Without a computer: a robot that knows no Wi-Fi opens its own network NW3D-xxxx. Join it with your phone and the setup page opens.

Když to nejdeTroubleshooting

  • Port se nenabízí: zkus jiný kabel nebo USB port. Na Windows 10/11 není potřeba žádný ovladač.
  • No port offered: try another cable or USB port. Windows 10/11 needs no driver.
  • Nahrávání se nespojí: podrž tlačítko BOOT, krátce stiskni RESET, BOOT pusť a zkus to znovu.
  • Flashing cannot connect: hold BOOT, tap RESET, release BOOT and try again.
  • nw3d-robot.local se neotevře (některé Androidy): použij IP adresu, kterou ukáže pravé oko robota.
  • nw3d-robot.local does not open (some Android phones): use the IP address shown on the robot's right eye.
  • Další verze se instalují přímo z webu robota (Aktualizace → Nainstalovat).
  • Later versions install from the robot's web page (Updates → Install).
